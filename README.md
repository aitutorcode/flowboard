# FlowBoard - Starter Repo

Starter scaffold for the FlowBoard project, a Kanban-style project management app you'll build in the AI Tutor Code course.

This repo contains a single file, `agents.md`, which is the briefing document your AI coding agent will use to build the app. Refine it as you like before running your agent.

## Setup

Clone this repo into your projects directory:

```
git clone https://github.com/<your-org>/flowboard.git
```

If you don't have git installed, [install it here](https://git-scm.com/downloads) (you may need to reboot afterwards).

Follow the course lessons from here.
